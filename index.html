O que é este guia

PostgreSQL é o banco de dados relacional open source mais avançado do mundo — usado por Instagram, Spotify, NASA. Ele guarda seus dados em tabelas com tipos fortes, garante integridade com constraints e responde consultas complexas em milissegundos.

  • Do zero: instalar, psql, criar banco/tabela, INSERT/SELECT/UPDATE/DELETE;
  • Consultas fortes: JOIN, GROUP BY, subconsultas, WITH (CTEs), CASE;
  • Integridade: PRIMARY KEY, FOREIGN KEY, UNIQUE, CHECK, transações BEGIN/COMMIT;
  • Produção: índices, EXPLAIN, usuários e GRANT, pg_dump, replicação.
