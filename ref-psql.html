Cola dos meta-comandos do psql

Tudo que começa com \ no psql é meta-comando: quem interpreta é o próprio psql (o cliente), não o servidor — por isso funcionam até sem banco nenhum. É a "chave de fenda" do dia a dia: listar bancos, ver tabelas, descrever estrutura, trocar de banco, sair. Esta é a cola deles.

Você vai aprender
  • \l lista bancos · \dt lista tabelas · \d tabela descreve a tabela.
  • \c banco troca de banco sem sair · \du lista usuários · \q sai.
  • \? mostra a ajuda completa · \x liga saída expandida · \i arquivo.sql roda um script.

Uma sessão típica no psql

loja_aurora=> \l
                                  List of databases
   Name    |  Owner   | Encoding |   Collate   |    Ctype    |   Access privileges
-----------+----------+----------+-------------+-------------+-----------------------
 loja_aurora | ana    | UTF8     | pt_BR.UTF-8 | pt_BR.UTF-8 |
 postgres  | postgres | UTF8     | pt_BR.UTF-8 | pt_BR.UTF-8 |
(2 rows)

loja_aurora=> \dt
            List of relations
 Schema |    Name    | Type  | Owner
--------+------------+-------+-------
 public | clientes   | table | ana
 public | itens_pedido | table | ana
 public | pedidos    | table | ana
 public | produtos   | table | ana
(4 rows)

loja_aurora=> \d produtos
                      Table "public.produtos"
  Column  |     Type     |       Modifiers
----------+--------------+------------------
 id       | integer      | not null
 nome     | text         | not null
 preco    | numeric(10,2)| check (preco >= 0)
 estoque  | integer      | default 0

loja_aurora=> \du
                                   List of roles
 Role name |                         Attributes
-----------+------------------------------------------------------------
 ana       | Create DB
 postgres  | Superuser, Create role, Create DB

loja_aurora=> \c postgres
You are now connected to database "postgres" as user "ana".
postgres=> \q
ana@notebook:~$

Experimente os meta-comandos no simulador

Missão 1 — \dt: liste as tabelas: \dt — a saída mostra itens_pedido entre as quatro.

Missão 2 — \l: liste os bancos: \l — a saída inclui o banco postgres.

Missão 3 — \d: descreva a tabela: \d clientes — a saída mostra as colunas com PRIMARY KEY e UNIQUE.

Missão 4 — \du: liste os usuários: \du — a saída mostra postgres como superuser.

Missão 5 — \c: troque de banco: \c postgres — a saída diz You are now connected to database "postgres". (Depois volte com \c loja_aurora.)

Missão 6 — \c com banco errado: \c banco_fantasma — o psql responde FATAL: database "banco_fantasma" does not exist.
