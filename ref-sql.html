Cola de comandos SQL — DDL, DML, DQL

SQL se divide em grupos: DDL cria e altera a estrutura (banco, tabelas, índices), DML mexe nos dados (inserir, atualizar, apagar) e DQL lê os dados (SELECT). Esta página é a cola dos quatro grupos + transações, com a sintaxe e um exemplo real no banco loja_aurora.

Você vai aprender
  • DDL: CREATE DATABASE/TABLE/INDEX/VIEW, ALTER TABLE, DROP, TRUNCATE.
  • DML: INSERT, UPDATE, DELETE — e as confirmações INSERT 0 1, UPDATE 2, DELETE 1.
  • DQL: SELECT com WHERE, ORDER BY, LIMIT, GROUP BY, HAVING e JOIN.
  • Transações: BEGIN, COMMIT, ROLLBACK.

Missão: aqueça na cola: SELECT nome, estado FROM clientes WHERE estado = 'PI'; — a saída mostra (3 rows).

Perigo: UPDATE/DELETE sem WHERE afeta a tabela inteira (UPDATE 5). O costume salva: rode BEGIN; antes de comandos grandes e confira com SELECT antes do COMMIT.
