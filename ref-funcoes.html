Cola de funções — agregação, texto, data e números

Funções no SQL fazem o trabalho pesado dentro do SELECT: somar, contar, formatar texto, calcular idade de uma data. Analogia: são as fórmulas da planilha — você não soma linha por linha na mão, usa SOMA(); no PostgreSQL é SUM(). Esta cola cobre as que caem em toda query.

Você vai aprender
  • Agregação: COUNT, SUM, AVG, MIN, MAX — sempre com GROUP BY para detalhes.
  • Texto: upper, lower, length, trim, ||, substring, replace, LIKE.
  • Data/hora: CURRENT_DATE, now(), age(), date_trunc, extract, to_char, interval.
  • Números: round, floor, ceil, abs.

Agregação — resumir várias linhas numa só

FunçãoO que devolveExemplo no loja_aurora
COUNT(*) / COUNT(col)número de linhas (a coluna conta só não-nulos)SELECT COUNT(*) FROM clientes; → 5
SUM(col)soma dos valoresSELECT SUM(preco) FROM produtos; → 164.10
AVG(col)média (com 2 casas)SELECT AVG(preco) FROM produtos; → 32.82
MIN(col) / MAX(col)menor / maior valorSELECT MIN(preco), MAX(preco) FROM produtos; → 4.50 / 59.90

Com GROUP BY, a agregação vira por grupo — e o HAVING filtra os grupos (o WHERE filtra linhas antes):

loja_aurora=> SELECT estado, COUNT(*) AS total FROM clientes GROUP BY estado ORDER BY estado;
 estado | total
--------+-------
 PE     |     1
 PI     |     3
 SP     |     1
(3 rows)

loja_aurora=> SELECT status, COUNT(*) AS total FROM pedidos GROUP BY status HAVING COUNT(*) >= 1 ORDER BY total DESC;
  status  | total
----------+-------
 entregue |     1
 enviado  |     1
 pendente |     1
(3 rows)

Missão 1: agrupe por estado: SELECT estado, COUNT(*) AS total FROM clientes GROUP BY estado; — (3 rows) (PI, SP, PE).

Missão 2: resuma a tabela inteira: SELECT COUNT(*) AS clientes, SUM(preco) AS valor_total FROM produtos; — uma linha só: (1 row).
