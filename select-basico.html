SELECT básico: WHERE, ORDER BY e LIMIT

SELECT é o comando de leitura — o "me traga as fichas que…" do arquivista. Você escolhe as colunas, a tabela, o filtro (WHERE), a ordem (ORDER BY) e o limite (LIMIT). Nesta aula, tudo isso consultando a loja_aurora no psql.

Você vai aprender
  • SELECT colunas FROM tabela; — e * para todas as colunas;
  • WHERE com =, <>, >, <, LIKE, IN, AND/OR;
  • ORDER BY coluna DESC para ordenar e LIMIT n para cortar;
  • Resultado vazio: (0 rows);
  • Erro clássico: tabela inexistente → relation "x" does not exist;
  • Praticar no simulador.

A anatomia da consulta

SELECT nome, estado
FROM clientes
WHERE estado = 'PI'
ORDER BY nome
LIMIT 3;
SELECT nome, estado
as colunas da resposta — use * para todas
FROM clientes
a tabela (planilha) de onde vêm os dados
WHERE estado = 'PI'
o filtro: só entram as linhas onde a condição é verdade
ORDER BY nome
ordena pelo nome em ordem crescente (DESC inverte)
LIMIT 3
devolve no máximo 3 linhas — mesmo que o filtro ache mais
;
encerra e executa

Exemplos no psql

Filtro por estado — as 3 fichas de Piauí:

loja_aurora=> SELECT nome, estado FROM clientes WHERE estado = 'PI';
   nome    | estado
-----------+--------
 Ana Souza | PI
 Beto Lima | PI
 Eva Nike  | PI
(3 rows)

Ordenando do mais caro para o mais barato e pegando só os 2 primeiros:

loja_aurora=> SELECT nome, preco FROM produtos ORDER BY preco DESC LIMIT 2;
  nome   | preco
---------+-------
 Camiseta | 59.90
 Boné     | 49.90
(2 rows)

Comparação numérica e filtro que não acha nada:

loja_aurora=> SELECT * FROM produtos WHERE preco < 10;
 id |  nome   | preco | estoque
----+---------+-------+---------
  3 | Adesivo |  4.50 |     200
(1 row)

loja_aurora=> SELECT * FROM clientes WHERE estado = 'XX';
 id | nome | email | cidade | estado | criado_em
----+------+-------+--------+--------+-----------
(0 rows)

Erros clássicos de SELECT

Tabela errada e comando errado

Digitar o nome da tabela errado dá ERROR: relation "nao_existe" does not exist — confira com \dt. E oublier o SELECT (ex.: SELEC * FROM clientes;) dá ERROR: syntax error at or near "selec": o SQL é exigente com a escrita.

loja_aurora=> SELECT * FROM nao_existe;
ERROR:  relation "nao_existe" does not exist
loja_aurora=> SELEC * FROM clientes;
ERROR:  syntax error at or near "selec"
LINE 1: SELEC * FROM clientes;
        ^

Dica: em tabela gigante, SELECT * pode devolver linha demais — prefira colunas específicas e LIMIT.

Pratique

Missão: ache as fichas de Piauí: SELECT nome, estado FROM clientes WHERE estado = 'PI'; → a saída inclui Eva Nike e (3 rows).

Missão: os 2 produtos mais caros: SELECT nome, preco FROM produtos ORDER BY preco DESC LIMIT 2; → o primeiro é a Camiseta.

Missão: produtos abaixo de 10 reais: SELECT * FROM produtos WHERE preco < 10; → só o Adesivo ((1 row)).

Missão: consulte uma tabela que não existe: SELECT * FROM nao_existe; → ERROR: relation "nao_existe" does not exist.

Resumo

  • SELECT colunas FROM tabela WHERE filtro ORDER BY coluna DESC LIMIT n;
  • * = todas as colunas · WHERE filtra · ORDER BY ordena · LIMIT corta.
  • Operadores: =, <>, >, <, LIKE 'A%', IN (...), AND/OR.
  • Sem resultado: (0 rows). Tabela errada: relation "x" does not exist. Comando errado: syntax error.
