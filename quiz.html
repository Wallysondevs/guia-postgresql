Gabarito comentado

  1. Banco relacional open source com tabelas tipadas e constraints. (aula: introdução)
  2. \dt lista tabelas (o \l lista bancos, \du usuários). (ref-psql)
  3. \d tabela descreve colunas, tipos e constraints. (meta-comandos)
  4. INSERT 0 1: o 0 é o OID, o 1 é a linha inserida. (INSERT)
  5. PRIMARY KEY = id único e não nulo da linha. (constraints)
  6. numeric(p,s) para dinheiro — exato; real é aproximado. (ref-tipos)
  7. JOIN … ON cruza as tabelas pela chave comum. (JOINs)
  8. GROUP BY + COUNT(*) = uma linha por grupo com a contagem. (agregações)
  9. 23505 = duplicate key (UNIQUE/PK); 23503 = foreign key. (ref-erros)
  10. ROLLBACK desfaz a transação; COMMIT grava. (transações — e o projeto reservas)
