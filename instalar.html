Instalar PostgreSQL no Linux e com Docker

Há duas formas comuns de ter um PostgreSQL rodando: instalando o pacote no Linux (o banco vira um serviço do sistema, como um arquivista sempre de plantão) ou subindo um container Docker (o arquivista inteiro dentro de uma caixa isolada, que você liga e desliga quando quiser). Aqui você aprende as duas — na máquina ana@notebook o PostgreSQL 16 já está no ar.

Você vai aprender
  • Instalar no Debian/Ubuntu com sudo apt install postgresql e ligar o serviço com systemctl;
  • Subir com Docker: docker run -e POSTGRES_PASSWORD=... -p 5432:5432 -d postgres:16;
  • Conferir a versão (psql --version) e entrar no psql (psql -U postgres);
  • O que significam a porta 5432 e a senha do usuário postgres;
  • No simulador: \l lista os bancos e \dt lista as tabelas do "servidor".

No Linux (Debian/Ubuntu): pacote + serviço

O pacote postgresql instala o servidor e cria um usuário de sistema chamado postgres. Depois de instalar, o banco vira um serviço (daemon) gerenciado pelo systemctl:

$ sudo apt update && sudo apt install postgresql
...
Setting up postgresql-16 (16.4-1) ...
$ sudo systemctl start postgresql   ← liga o serviço agora
$ sudo systemctl enable postgresql  ← liga sozinho no boot
$ psql --version
psql (PostgreSQL) 16.4
$ sudo -u postgres psql
psql (16.4)
Type "help" for help.

postgres=# \q

O sudo -u postgres psql entra como o superusuário postgres — no Linux, por padrão, só esse usuário de sistema entra local sem senha. O prompt vira postgres=# (o # avisa: você é o chefão).

Com Docker: o banco inteiro num container

Com Docker instalado, um comando sobe o PostgreSQL numa caixa isolada:

$ docker run --name meu-postgres -e POSTGRES_PASSWORD=senha123 -p 5432:5432 -d postgres:16
a1f9c2d8e7b6...
$ docker ps
CONTAINER ID   IMAGE         STATUS         PORTS                    NAMES
a1f9c2d8e7b6   postgres:16   Up 5 seconds   0.0.0.0:5432->5432/tcp   meu-postgres
$ docker exec -it meu-postgres psql -U postgres
psql (16.4)
postgres=# \q

Traduzindo o docker run:

  • --name meu-postgres — nome do container;
  • -e POSTGRES_PASSWORD=senha123 — variável de ambiente: a senha do superusuário postgres (obrigatória na primeira subida);
  • -p 5432:5432 — publica a porta do banco: 5432 no seu computador aponta para a 5432 do container;
  • -d — roda em segundo plano (detached);
  • postgres:16 — a imagem oficial do Docker Hub, versão 16.

De fora do container, você entra com psql -h localhost -U postgres (vai pedir a senha). Para parar: docker stop meu-postgres; para subir de novo: docker start meu-postgres.

Qual usar?

FormaComandoQuando usar
Pacote do Linuxsudo apt install postgresqldesenvolvimento no próprio SO, serviço sempre ligado
Dockerdocker run ... postgres:16testes, vários bancos ao mesmo tempo, não sujar o SO
Nuvem gerenciada (RDS, Supabase…)painel webprodução — o provedor cuida de backup e atualização
Senha de exemplo, só para estudo local

senha123 serve para o container de teste — em produção use senha forte e nunca exponha a porta 5432 na internet. E anote a senha: se você recriar o container sem o mesmo volume, os dados novos não reconhecem a senha antiga.

Conferindo: o servidor está no ar

Depois de instalar (qualquer forma), entre no psql e olhe os bancos com \l — se aparecer uma lista, o arquivista está de plantão:

$ psql -U ana -d loja_aurora
psql (16.4)
loja_aurora=> \l
+--------------+--------------+
| Name         | Owner        |
+--------------+--------------+
| postgres     | ana          |
| loja_aurora  | ana          |
+--------------+--------------+
(2 rows)

Missão: no simulador (que já é o servidor ligado), rode \l. Você vê os 2 bancos da máquina: postgres e loja_aurora — prova de que o PostgreSQL está no ar.

Missão: rode \dt e veja as 4 tabelas do banco loja_aurora — a "loja" que vamos usar no curso inteiro.

Resumo

  • Linux: sudo apt install postgresql + systemctl start/enable postgresql; entrar com sudo -u postgres psql.
  • Docker: docker run --name meu-postgres -e POSTGRES_PASSWORD=... -p 5432:5432 -d postgres:16; entrar com docker exec -it meu-postgres psql -U postgres.
  • O servidor ouve na porta 5432; o cliente de terminal é o psql.
  • Conferiu a instalação? psql --version e \l listando os bancos.
