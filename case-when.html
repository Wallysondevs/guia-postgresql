CASE WHEN: o if/else dentro do SELECT

Nem sempre o dado sai "pronto" da tabela — às vezes você precisa classificar na hora da consulta: preço baixo/médio/alto, pedido pendente ou concluído. O CASE WHEN é o if/else do SQL: testa condições e devolve um valor para cada caso, como etiquetar produtos numa prateleira.

Você vai aprender
  • CASE WHEN condição THEN valor ... ELSE valor END (CASE "buscado");
  • CASE expressão WHEN valor THEN ... (CASE "simples");
  • Dar apelido à coluna calculada (AS faixa);
  • Usar CASE dentro de agregação (SUM(CASE ...)) e no ORDER BY;
  • A pegadinha: sem ELSE, quem não casa com nada ganha NULL;
  • Praticar no simulador de psql.

CASE buscado: classificar por faixa

Vamos etiquetar cada produto do banco loja_aurora como barato, médio ou caro, só olhando o preço:

loja_aurora=> SELECT nome, preco,
               CASE WHEN preco < 20 THEN 'barato'
                    WHEN preco < 50 THEN 'medio'
                    ELSE 'caro'
               END AS faixa
             FROM produtos;
   nome   | preco |  faixa
----------+-------+---------
 Camiseta | 59.90 | caro
 Caneca   | 29.90 | medio
 Adesivo  |  4.50 | barato
 Poster   | 19.90 | barato
 Boné     | 49.90 | medio
(5 rows)

O PostgreSQL testa os WHEN na ordem e usa o primeiro que for verdade; se nenhum for, cai no ELSE. Por isso a ordem importa: < 20 antes de < 50.

CASE
começa o condicional
WHEN preco < 20 THEN 'barato'
se a condição for verdade, vale esse valor
WHEN preco < 50 THEN 'medio'
se não, testa o próximo
ELSE 'caro'
se nenhum casou, vale isso
END
fecha o CASE (obrigatório!) e AS faixa dá nome à nova coluna

CASE simples: traduzir códigos

Quando você compara a mesma expressão com vários valores fixos, a forma simples é mais curta — como traduzir o status do pedido para português:

loja_aurora=> SELECT status,
               CASE status WHEN 'entregue' THEN 'concluido'
                           ELSE 'aguardando'
               END AS situacao
             FROM pedidos;
  status  |  situacao
----------+------------
 entregue | concluido
 enviado  | aguardando
 pendente | aguardando
(3 rows)

É equivalente a CASE WHEN status = 'entregue' THEN ..., só que sem repetir a coluna.

CASE dentro de agregação e no ORDER BY

O CASE devolve um valor, então pode ir dentro de qualquer função. Aqui contamos quantos pedidos já foram entregues num total só:

loja_aurora=> SELECT COUNT(*) AS total,
               SUM(CASE WHEN status = 'entregue' THEN 1 ELSE 0 END) AS entregues
             FROM pedidos;
 total | entregues
-------+-----------
     3 |         1
(1 row)

E no ORDER BY ele vira régua de prioridade — "pendente primeiro, depois enviado, por último entregue":

loja_aurora=> SELECT id, status FROM pedidos
             ORDER BY CASE WHEN status = 'pendente' THEN 0
                           WHEN status = 'enviado'  THEN 1
                           ELSE 2 END;
 id |  status
----+----------
  3 | pendente
  2 | enviado
  1 | entregue
(3 rows)

A pegadinha: sem ELSE vira NULL

Se você esquece o ELSE, quem não casa com nenhum WHEN ganha NULL (aparece vazio no psql) 
loja_aurora=> SELECT nome, CASE WHEN preco > 50 THEN 'caro' END AS faixa
             FROM produtos;
   nome   | faixa
----------+-------
 Camiseta | caro
 Caneca   |
 Adesivo  |
 Poster   |
 Boné     |
(5 rows)

Só a Camiseta (59.90) passou no teste; as outras ganharam NULL. E sem o END o comando nem compila:

loja_aurora=> SELECT CASE WHEN preco > 50 THEN 'caro' FROM produtos;
ERROR:  syntax error at or near "FROM"
LINE 1: SELECT CASE WHEN preco > 50 THEN 'caro' FROM produtos;
                                              ^

Missões no simulador

O simulador não interpreta CASE, mas as peças que ele usa (ORDER BY, WHERE, GROUP BY) dão para praticá-las:

Missão 1: ache o produto mais caro (seria o 'caro' do CASE): SELECT nome FROM produtos ORDER BY preco DESC LIMIT 1; — a saída mostra Camiseta.

Missão 2: conte os pedidos por status: SELECT status, COUNT(*) FROM pedidos GROUP BY status; — a saída mostra pendente.

Missão 3: ache o produto esgotado (no CASE seria 'esgotado'): SELECT nome FROM produtos WHERE estoque = 0; — a saída mostra Poster.

Missão 4: liste os clientes de PI em ordem alfabética: SELECT nome FROM clientes WHERE estado = 'PI' ORDER BY nome; — a saída mostra Eva Nike.

  • CASE WHEN cond THEN valor ... ELSE valor END — if/else no SELECT; os WHEN são testados na ordem.
  • CASE expr WHEN valor THEN ... — forma curta quando a comparação é com a mesma coluna.
  • Sem ELSE, o resultado é NULL; sem END, dá syntax error.
  • CASE vira valor, então funciona dentro de SUM, COUNT, ORDER BY etc.
