Cola de erros — código SQLSTATE → causa → solução

O PostgreSQL fala em códigos: toda mensagem de erro traz um SQLSTATE de 5 caracteres (ex.: 23505). Aprenda a ler a mensagem que o servidor já diz o quê e onde — e esta cola diz por quê e como consertar. Dá para provocar os quatro primeiros no psql simulado abaixo.

Você vai aprender
  • A anatomia da mensagem: ERROR: … + DETAIL + LINE 1: … ^ apontando a coluna do erro.
  • Os códigos de classe 42 (sintaxe/tabela), 23 (integridade), 22 (valor inválido), 08/28/3D (conexão) e 40/55 (lock).
  • Que no psql dá para ver o código com \errverbose após um erro.

Anatomia da mensagem de erro

ERROR:
a classe do problema em texto
relation "x" does not exist
a explicação: o que não foi encontrado
LINE 1: SELECT * FROM x;
o trecho do comando que causou o erro
^
a setinha marca a coluna exata onde o servidor parou
loja_aurora=> SELECT * FROM tabela_fantasma;
ERROR:  relation "tabela_fantasma" does not exist
LINE 1: SELECT * FROM tabela_fantasma;
                      ^

42703ERROR: column "x" does not existColuna não existe naquela tabela (erro de digitação).\d tabela para ver as colunas; o próprio erro às vezes sugere: HINT: Perhaps you meant…
42601ERROR: syntax error at or near "…"Comando mal formado (vírgula sobrando, palavra reservada errada, FROM faltando).A LINE 1: … ^ mostra onde parou. Revise vírgulas e a ordem: SELECT … FROM … WHERE ….
23505ERROR: duplicate key value violates unique constraint "t_col_key" + DETAIL: Key (col)=(valor) already exists.Valor repetido em coluna UNIQUE ou PRIMARY KEY.Use outro valor, ou faça UPDATE na linha existente, ou INSERT … ON CONFLICT (col) DO UPDATE (upsert).
23503ERROR: insert or update on table "t" violates foreign key constraint "t_col_fkey"Referenciar um id que não existe na tabela pai (ou apagar o pai com filhos).Insira o pai antes; confira com SELECT; ou declare ON DELETE CASCADE/SET NULL na FK.
23502ERROR: null value in column "col" violates not-null constraintINSERT sem valor numa coluna NOT NULL.Informe o valor ou tire o NOT NULL (com ALTER TABLE).
23514ERROR: new row violates check constraint "t_col_check"Valor que quebra uma regra CHECK (ex.: preco >= 0 com preço negativo).Corrija o valor para obedecer à regra.
22P02ERROR: invalid input syntax for type integer: "abc"Texto onde o banco esperava número/data (ex.: WHERE id = 'abc').Converta: WHERE id = 1 (sem aspas no número) ou 'abc'::integer para testar.
22001ERROR: value too long for type character varying(2)Texto maior que o limite do varchar(n)/char(n).Use text (sem limite) ou aumente o n.
08006could not connect to server: Connection refusedServidor parado ou porta errada (padrão 5432).pg_isready; suba o serviço (sudo systemctl start postgresql); confira a porta.
28P01FATAL: password authentication failed for user "ana"Senha errada (ou usuário errado).Confira a senha; no psql, \password ana troca a senha; veja pg_hba.conf.

Provoque os erros no simulador (treino de reconhecimento)

Missão 1 — 42P01: consulte uma tabela que não existe: SELECT * FROM tabela_fantasma; — relation "tabela_fantasma" does not exist.

Missão 2 — 42601: erre a palavra-chave: SELEC * FROM clientes; — syntax error at or near "selec".

Missão 3 — 23505: repita um email: INSERT INTO clientes (nome, email) VALUES ('Ana Duplicada', 'ana@email.com'); — duplicate key value violates unique constraint.

Missão 4 — 23503: pedido de cliente inexistente: INSERT INTO pedidos (cliente_id) VALUES (999); — violates foreign key constraint.
