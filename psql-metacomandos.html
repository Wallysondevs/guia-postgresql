Meta-comandos do psql: \dt, \d, \du, \l

Além do SQL, o psql tem seus próprios comandos, que começam com \ — são os meta-comandos: eles não vão para o servidor, não precisam de ; e servono para inspecionar e navegar. Nesta aula: a família inteira, com o raio-x da tabela clientes.

Você vai aprender
  • Meta-comando = comando do psql (começa com \), sem ;;
  • \l bancos · \c banco conecta · \dt tabelas · \d tabela estrutura · \du usuários · \? ajuda · \q sai;
  • Ler o \d clientes: colunas, tipos e restrições (PRIMARY KEY, NOT NULL, UNIQUE);
  • Praticar no simulador.

A família dos meta-comandos

ComandoFazExemplo de saída
\llista os bancos do servidorpostgres, loja_aurora
\c bancoconecta em outro bancoYou are now connected to database "..."
\dtlista as tabelas do banco atualclientes, produtos, pedidos, itens_pedido
\d tabeladescreve a estrutura da tabela (colunas, tipos, restrições)Table "public.clientes" + colunas
\dulista os usuários (roles) do servidorpostgres (superuser), ana
\?mostra a ajuda dos meta-comandosa lista completa
\qsai do psql, de volta ao shell$

\dt: quais planilhas eu tenho?

loja_aurora=> \dt
+--------------+--------------+
| Name         | Owner        |
+--------------+--------------+
| clientes     | ana          |
| produtos     | ana          |
| pedidos      | ana          |
| itens_pedido | ana          |
+--------------+--------------+
(4 rows)

\d clientes: o raio-x da planilha

O \d abre a tabela e mostra cada coluna, seu tipo e suas restrições:

\d
"describe": descreve a estrutura
clientes
a tabela que você quer abrir
loja_aurora=> \d clientes
Table "public.clientes"
+-----------+----------+----------------------+
| Column    | Type     | Modifiers            |
+-----------+----------+----------------------+
| id        | integer  | PRIMARY KEY          |
| nome      | text     | NOT NULL             |
| email     | text     | UNIQUE               |
| cidade    | text     |                      |
| estado    | char(2)  |                      |
| criado_em | date     | DEFAULT CURRENT_DATE |
+-----------+----------+----------------------+

É o mesmo CREATE TABLE da aula anterior, relido pelo banco: id é PRIMARY KEY, nome é NOT NULL, email é UNIQUE.

\du: quem pode entrar no servidor

loja_aurora=> \du
+-----------+---------------------+
| Role name | Attributes          |
+-----------+---------------------+
| postgres  | superuser           |
| ana       | CREATE DATABASE     |
+-----------+---------------------+
(2 rows)

Os roles (usuários) do servidor: postgres é o superuser (pode tudo) e ana pode criar bancos. No Nível 3 você aprende a criar usuários e dar permissões com GRANT.

Pratique

Missão: liste as tabelas: \dt → as 4 planilhas do loja_aurora, incluindo itens_pedido.

Missão: abra o raio-x da planilha clientes: \d clientes → a coluna email aparece com a restrição UNIQUE.

Missão: veja quem pode entrar no servidor: \du → postgres aparece como superuser.

Missão: liste os bancos: \l → postgres e loja_aurora.

Resumo

  • Meta-comandos começam com \, são interpretados pelo psql e não levam ;.
  • \l bancos · \c conecta · \dt tabelas · \d t estrutura · \du usuários · \? ajuda · \q sai.
  • \d clientes relê o CREATE TABLE: tipos + PRIMARY KEY/NOT NULL/UNIQUE por coluna.
